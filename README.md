# 📊 E-commerce Sales Dashboard — Excel

## 📌 Project Overview
An interactive E-commerce Sales Dashboard built using Microsoft Excel
to analyze sales performance, customer demographics, channels, and
delivery outcomes.

## 🛠️ Tools & Skills
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers
- Data Analysis
- Dashboard Design

## 📊 Key Insights
- Analyzed 31,000+ orders
- Women customers contributed 64% of revenue
- Amazon was the top channel with 35.5% of orders
- Maharashtra, Karnataka, and Uttar Pradesh led state-wise sales
- Successful delivery rate was 92%+
